# Python 4000

## 📘 Overview
Each folder represents a separate project demonstrating key Python programming skills — including file I/O, data analysis, class design, GUI implementation, and algorithmic problem-solving.

## 🧩 Projects Included

| Project | Description |
|----------|--------------|
| **Animals** | Demonstrates inheritance and polymorphism using a class hierarchy for different animal types. |
| **Books** | A file-handling project for managing and searching a collection of books. |
| **Cipher** | Implements simple encryption/decryption algorithms to explore string manipulation. |
| **FinalProject** | A data visualization and analysis tool using Pandas and Matplotlib. |
| **FlooringEstimator** | Calculates cost estimates for flooring based on room dimensions and material type. |
| **Gradebook** | Reads and analyzes student grades from CSV files. |
| **ImprovedZombieOutbreakSim** | A simulation project modeling population spread dynamics in a zombie outbreak. |
| **MovieAnalyzer** | Reads movie data and performs statistical analysis with sorting and filtering. |
| **NumStat** | Performs numerical and statistical calculations from a dataset. |


## ⚙️ Technologies Used
- **Python 3**
- **Pandas**
- **Matplotlib**
- **NumPy**
- File I/O, OOP, and exception handling
